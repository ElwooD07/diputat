# Language Policy

## 🌍 English Only

This project uses **English** for all content.

### What Must Be in English:
- ✅ All code (variables, functions, classes)
- ✅ All comments in code
- ✅ All documentation (README, guides, etc.)
- ✅ All commit messages
- ✅ All pull request descriptions
- ✅ All issue descriptions
- ✅ Configuration file comments

### Why English?
- **International collaboration** - Makes project accessible globally
- **Consistency** - One language for entire codebase
- **Tooling** - Better IDE support and spell checking
- **Documentation** - Easier to maintain and search
- **Community** - Larger potential contributor base

### Exception:
- User-facing content (UI strings, error messages) can be localized

## Enforcement

This standard is enforced through:
1. **Code review** - All PRs checked for English content
2. **Spell checker** - VSCode configured for English only
3. **Project config** - `.diputatrc.json` defines this standard
4. **Documentation** - This file and `STANDARDS.md`

## Configuration Files

- [.diputatrc.json](.diputatrc.json) - Project configuration
- [STANDARDS.md](STANDARDS.md) - Complete standards documentation
- [.vscode/settings.json](.vscode/settings.json) - Editor configuration

## Need Help?

If you're not comfortable with English:
- Use translation tools for writing
- Ask team members for review
- Reference existing code for examples

---

**Remember**: Quality of code matters more than perfect English. We'll help improve language during code review! 🚀
