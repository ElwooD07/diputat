# Schemas (Document Schemas)

Description of document structure for NoSQL database.

## Files

- `official.schema.json` - Public official schema
- `statement.schema.json` - Statement schema
- `verification.schema.json` - Verification result schema

## Principles

Schemas are **flexible** and represent mental model:
- Can change during research
- Support additional fields
- Not rigid constraints

## JSON Schema

JSON Schema is used for validation (optional).
