# Assets

Static resources for the React dashboard.

## Structure

```text
assets/
├── images/        # Images and illustrations
├── icons/         # Icons
├── fonts/         # Optional local fonts
└── data/          # Static fallback files if needed later
```

## Usage

Import assets from React components or reference them from CSS.

## Optimization

- Compress images before commit
- Prefer SVG for icons
- Use modern formats for large images
