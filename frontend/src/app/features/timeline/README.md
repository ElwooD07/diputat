# Timeline Module

Chronological analysis of statements and verifications.

## Components

- `timeline-view` - Visual timeline
- `timeline-event` - Timeline event
- `timeline-filter` - Period filters
- `comparison-view` - Compare statements over time

## Functionality

- Chronological event display
- Compare statements from same official over time
- Analyze position changes and contradictions
- Visualize statement evolution
- Filter by date, official, topic

## Visualization

- Vertical/horizontal timeline
- Interactive event points
- Links between contradicting statements
