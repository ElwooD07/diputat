# Statements Module

Module for working with statements.

## Components

- `statements-list` - Statements list
- `statement-detail` - Detailed view
- `statement-filter` - Filters and search

## Functionality

- View all statements
- Filter by date, source, status, official
- Search by text
- Sort by relevance
- Link to verification results

## Data

Displays statements from various media sources collected by scraper.
