# Verification Module

Fact-checking results module.

## Components

- `verification-result` - Verification result
- `evidence-list` - Evidence list
- `confidence-meter` - Confidence indicator
- `verdict-badge` - Verdict badge (true/false)

## Visualization

- Truth/false scale
- Confidence percentage
- Evidence sources with links
- Charts and diagrams

## Functionality

- View verification results
- Evidence analysis
- Compare with historical data
